┌─ ACTION SPACE ──────────────────────────────────────────────────────────────┐
│                                                                             │
│  CONTINUOUS (SAC, TD3, DDPG, A3C, PPO):                                     │
│    action_type = "continuous"                                               │

│    action_type = "discrete"                                                 │
│    action_bounds = (-1.0, 1.0)                                              │
│    n_action_bins = 5  # Creates 5 actions: [-1, -0.5, 0, 0.5, 1]            │
│    step(action) expects int in [0, 4]                                       │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ REWARD STRUCTURE ──────────────────────────────────────────────────────────┐
│                                                                             │
│  reward = -(state_cost + control_cost)                                      │
│         = -(φ(x) + α * u²)                                                  │
│                                                                             │
│  Default φ(x) = 0.5 * (1 + tanh(x/2))  [penalizes x deviation from 0]       │
│  Default α = 1.0  [control cost weight]                                     │
│                                                                             │
│  Higher reward = better. Agents learn to minimize φ(x) while conserving u.  │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ PHYSICS (HARDCODED - CANNOT CHANGE) ────────-──────────────────────────────┐
│                                                                             │
│  Lorenz Equations:          RK4 Integration:                                │
│    σ = 10 (PRANDTL)           Accurate 4th-order Runge-Kutta                │
│    ρ = 28 (RAYLEIGH)          dt = 0.01                                     │
│    β = 8/3 (B)                Time step size                                │
│                                                                             │
│  dx/dt = σ(y - x) + u    ← Control injected here (additive on x)            │
│  dy/dt = x(ρ - z) - y                                                       │
│  dz/dt = xy - βz                                                            │
│                                                                             │
│  Lyapunov exponent λ = 0.9056  [used to convert Lyapunov times ↔ steps]     │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ TERMINATION CONDITIONS ────────────────────────────────────────────────────┐
│                                                                             │
│  Episode ends when:                                                         │
│    1. step_count >= horizon (primary termination)                           │
│    2. norm(state) > divergence_threshold (divergence detected)              │
│    3. state contains NaN (numerical instability)                            │
│                                                                             │
│  Check info dict for termination reason:                                    │
│    info.get("horizon_reached") == True  →  Normal termination               │
│    info.get("diverged") == True  →  Divergence or NaN detected              │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
